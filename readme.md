# Coca Cola — Practical Landing Page

Modernized landing page migrated to **Next.js 16.2**, **TypeScript**, **Tailwind CSS**, **shadcn/ui**, and **pnpm**, preserving the original legacy layout and visual identity.

## Stack

- Next.js 16.2 (App Router)
- TypeScript
- Tailwind CSS v4
- shadcn/ui primitives
- Lenis (smooth scroll)
- GSAP + ScrollTrigger (section motion)
- pnpm

## Scripts

```bash
pnpm install
pnpm dev        # development server
pnpm build      # production build
pnpm start      # production server
pnpm lint       # ESLint
pnpm type-check # TypeScript
```
